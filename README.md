# AI Assisted End to End Testing with Playwright Workshop

Follow the branches in this order to walk through the workshop progression:

4. **[03-improve-prompt](https://github.com/BMayhew/ai-assisted-end-to-end-testing-playwright-workshop/tree/03-improve-prompt)** — V2/V3 critical path plans with improved prompts and models
5. **[04-create-tests](https://github.com/BMayhew/ai-assisted-end-to-end-testing-playwright-workshop/tree/04-create-tests)** — Working tests, page objects, and prompt iteration
